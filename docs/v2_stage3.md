# Stage 3 AND(7,8) original-neuron development study

The researcher explicitly authorizes original-neuron zero/clamp interventions for this case, superseding the Stage 2 pilot's prohibition for this one study. Teacher and transcoder weights remain frozen. No other case, new training, or further sweep is authorized.

Protocol: configs/stage3_and78.yaml under experiments/v2_pairwise_superposition. New contexts use the original generator at a separate seed, clear pair bits, restrict supported background density to3/4, deduplicate and split into1,000 discovery and1,000 held-out contexts, plus200 held-out OOD stress contexts. All complete corner identities are disjoint across these development partitions. Known test overlap and old AND78 contexts are excluded. Original training/validation overlap is reported. The final reserved file is not opened; unknown overlap with its identities cannot be ruled out, so future final confirmation needs an exclusion audit against published development keys.

Selections and predictions are frozen before held-out inference. Original subset coefficients are1; no W1/W2/readouts are retrained. Comparable budgets1/3/5/10/20 include a signed direct-native search, a net-only greedy/swap search, absolute attribution, transcoder-guided signed search and random/contribution-matched groups. Signed selection uses readout-sign channels; individual finite-interaction signs can vary with gates. Matching quality and unavoidable group overlap are reported.

Intervention zeroing/clamping changes runtime hidden activations only. Clamp values are discovery00 means, fixed across evaluation contexts. Exact contribution identities are correctness checks; discovery-mean and compact original-threshold predictions are the nontrivial generalization tests. The compact threshold summary keeps original pair coefficients, optionally two discovery-variable context reads per neuron, and replaces omitted context reads by discovery means. No new neural network is trained. A fixed useful-fidelity threshold of pair-response RMSE≤0.05 and interaction MAE≤0.05 is declared in config; smallest successful tested budget is not a claim of global minimality (k2 native groups are not searched).

Actual commands/logs, source/config snapshots, frozen hypotheses and all results are stored in runs/reports/execution_logs/stage3-and78-20261027. No XOR study is performed; other semantic outputs are recorded only as collateral responses to AND78 neuron interventions.
